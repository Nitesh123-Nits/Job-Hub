# JobHub

One-page PWA with links to job boards, remote job sites and company career pages, plus role/location search builders and "who is hiring now" searches. Installable on phone and desktop; works offline for the page itself.

## Run locally
Serve the folder over HTTP (service workers need it):

    python3 -m http.server 8000

## Deploy
GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.
